AI FinOps Dashboard

Features
- Total AI Cost
- Total Requests
- Input Tokens
- Output Tokens
- Cost by Model
- Cost by Environment
- Cost by Application
- Langfuse Integration

Tech Stack
- Python
- Streamlit
- Langfuse
- Pandas
- Plotly

Run Locally
1. Clone repo
2. Create .env
3. pip install -r requirements.txt
4. streamlit run dashboard.py
